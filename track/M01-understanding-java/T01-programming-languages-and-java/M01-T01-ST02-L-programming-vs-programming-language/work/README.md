# Programming vs Programming Language

## What Is Programming?

Programming is the process of understanding a problem, creating a logical solution, writing code, testing it, and fixing errors.

## What Is a Programming Language?

A programming language is a set of rules and syntax used to communicate instructions to a computer.

## What Is Java?

Java is a programming language used to write programs and convert our problem-solving logic into code that a computer can execute.

## What Is Syntax?

Syntax is the set of rules that defines how code must be written correctly in a programming language.

## Programming and Java

Programming is the overall process of solving a problem using logic, while Java is one of the programming languages used to express that logic as code.

## What Remained the Same?

The problem-solving logic and the steps of the solution remained the same between pseudocode and Java.

## What Changed?

The solution was written using Java-specific syntax such as variables, if-else statements, braces, semicolons, and System.out.println().

## My Final Understanding

Programming helps me: solve problems by developing logical and structured solutions.

Java helps me: express my programming logic as executable code.

Syntax tells me: how to write Java code according to the rules of the language.
